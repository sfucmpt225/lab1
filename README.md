##  IDE Restriction
Moving forward, all labs must be completed using NetBeans. I know some of you may prefer VS Code, IntelliJ IDEA, or other IDEs, and honestly, I understand that NetBeans can feel a little old-school. However, the professor uses NetBeans during lectures, and I use NetBeans to compile and run your lab submissions.

To avoid compatibility issues and unnecessary friction when grading, we need to standardize the IDE we use for the course. If your lab does not compile or run correctly in NetBeans because it was developed using another IDE, the lab will receive a grade of zero.

Please use NetBeans for all labs going forward. This will help ensure that your code works correctly in the same environment used for teaching and grading.

## Intro
In this lab, you will identify and fix five deliberately introduced compilation errors in a library management program. Your task is to locate each error, determine the cause, correct it, and successfully compile and run the program.

## Objectives
* Analyze a Java codebase consisting of multiple classes and interfaces.
* Edit, compile, and run Java programs using NetBeans.
* Review and apply fundamental Java programming concepts.
